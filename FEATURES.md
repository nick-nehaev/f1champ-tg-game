# Новые функции F1 Championship

## Обзор обновления

Добавлено множество новых функций для улучшения игрового процесса:

## 1. Система пилотов

### Характеристики пилотов
- **5 уровней** пилотов (от новичка до легенды)
- **Случайные имена** генерируются из пула 130+ реальных пилотов F1
- **4 характеристики**:
  - Навык (Skill) - общее мастерство пилота
  - Опыт (Experience) - влияет на стабильность
  - Стабильность (Consistency) - снижает шанс DNF
  - Агрессивность (Aggression) - стиль вождения

### Влияние на гонку
- Пилоты влияют на **30% результата гонки**
- Можно назначить 2 пилотов в команду
- Пилоты влияют на квалификацию и гонку

### API Endpoints
```
GET  /api/pilots              - Все доступные пилоты
GET  /api/pilots/team         - Пилоты команды
POST /api/pilots/buy          - Купить пилота
POST /api/pilots/assign       - Назначить пилотов
```

## 2. Квалификация

### Система квалификации
- Проводится **автоматически перед каждой гонкой**
- Определяет стартовую позицию на grid
- Зависит от:
  - Характеристик машины (60%)
  - Навыков пилотов (30%)
  - Случайности (10%)

### Влияние на гонку
- Стартовая позиция дает **до 10% бонуса** к результату
- Лучшая позиция = меньше шанс попасть в аварию в первом повороте

## 3. Система наборов/кейсов

### Типы наборов
1. **Ежедневный набор** 🎁
   - Доступен каждые 24 часа
   - Содержит 1 награду
   - Базовые компоненты и деньги

2. **Бронзовый набор** 🥉
   - За 3 место в гонке
   - 2 награды
   - Компоненты 2-3 уровня

3. **Серебряный набор** 🥈
   - За 2 место в гонке
   - 2 награды
   - Компоненты 3-4 уровня

4. **Золотой набор** 🥇
   - За 1 место в гонке
   - 2 награды
   - Компоненты 4-5 уровня

5. **Сезонный набор** 🏆
   - За топ-3 в конце сезона
   - 5 наград
   - Лучшие компоненты и пилоты

### Механика открытия
- Таймер: **10 секунд** (настраивается)
- Можно пропустить за **10 Max** валюты
- Награды применяются автоматически

### Возможные награды
- **Компоненты машины** (разных уровней)
- **Пилоты** (случайные, разных уровней)
- **Деньги** (500-20,000 в зависимости от типа)
- **Max валюта** (1-50, редкая награда)

### API Endpoints
```
GET  /api/crates                    - Наборы команды
GET  /api/crates/can-claim-daily    - Можно ли получить ежедневный
POST /api/crates/claim-daily        - Получить ежедневный набор
POST /api/crates/skip-wait          - Пропустить ожидание (10 Max)
POST /api/crates/open               - Открыть набор
```

## 4. Донатная валюта "Max"

### Получение Max
- **Начальный бонус**: 50 Max при создании команды
- **Из наборов**: редкая награда (1-5% шанс)
- **Рефералы**: 25 Max за приглашенного друга
- **Покупка**: через Telegram Stars (готовится)

### Использование Max
- Пропуск ожидания открытия кейса: **10 Max**
- В будущем: ускорение других процессов

## 5. Реферальная система

### Механика
- Каждый игрок получает **реферальный код** (его Telegram ID)
- При создании команды можно указать реферальный код

### Награды
**Реферер получает**:
- 5,000$ игровых денег
- 25 Max валюты

**Приглашенный получает**:
- 1,000$ бонус

### API Endpoints
```
GET /api/referrals - Список рефералов и статистика
```

## 6. Автоматические сезоны

### Система сезонов
- Сезон длится **30 дней**
- По окончании автоматически начинается новый
- Очки обнуляются, но команды и инвентарь сохраняются

### Награды за сезон
**Топ-5 команд получают**:
- Топ-3: Сезонный набор (5 наград)
- Все топ-5: Золотой набор

## 7. Обновленная игровая механика

### Распределение влияния на результат
- **50%** - Характеристики машины
- **30%** - Навыки пилотов
- **10%** - Позиция на старте (квалификация)
- **10%** - Случайность

### Шанс DNF (Did Not Finish)
- Базовый: 25%
- Снижается надежностью машины (до -15%)
- Снижается стабильностью пилота (до -5%)
- Минимум: 3%

- `pilots` - Пилоты

## 8. Система стратегии гонок

### Механика
- Перед каждой гонкой команда выбирает стратегию
- **Питстопы**: количество и круги остановок
- **Типы шин**: мягкие (fast, быстро изнашиваются), средние (баланс), жесткие (медленные, долговечные)
- Дождевые и промежуточные шины для плохой погоды

### API Endpoints
```
POST /api/strategy/:raceId - Установить стратегию
GET  /api/strategy/:raceId  - Получить стратегию
```

## 9. Покупаемые наборы

### Типы
1. **Базовый набор** - 500$
   - 1 награда
   - Только компоненты и пилоты 1 уровня

2. **Стандартный набор** - 1500$
   - 2 награды
   - Компоненты и пилоты 1-2 уровня

### API Endpoints
```
POST /api/crates/purchase - Купить набор
```

## 10. Система крафта

### Механика
- 20 одинаковых компонентов одного типа и уровня → 1 компонент того же типа следующего уровня
- Нельзя крафтить компоненты 5 уровня (максимальный)

### API Endpoints
```
POST /api/crafting/craft       - Скрафтить компонент
GET  /api/crafting/available   - Получить доступные для крафта группы
```

## 11. Визуализация гонок

### Схемы трасс
Включены упрощенные схемы 5 реальных трасс:
- Монако (50 кругов)
- Сильверстоун (45 кругов)
- Монца (48 кругов)
- Судзука (44 круга)
- Спа-Франкоршам (40 кругов)

### Данные визуализации
- Позиции команд на трассе (цветные кружочки)
- Текущий круг
- Прогресс по кругу (0-1)
- Статус питстопа (isInPit)
- Тип установленных шин
