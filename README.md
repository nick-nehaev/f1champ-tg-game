# F1 Championship Telegram Game

Игра в Формулу 1 для Telegram Web App, где игроки могут:
- Собирать свою команду
- Строить и улучшать машину
- Участвовать в этапах чемпионата (каждые 2 дня)
- Соревноваться с другими игроками
- Получать награды в конце сезона (каждый месяц)

## Структура проекта

- `frontend/` - React + TypeScript + Vite (Telegram WebApp)
- `backend/` - Node.js + Express + TypeScript + PostgreSQL
- `shared/` - Общие типы и утилиты

## Запуск проекта

### Разработка
```bash
npm install
npm run dev
```

### Backend отдельно
```bash
npm run dev:backend
```

### Frontend отдельно
```bash
npm run dev:frontend
```

## Игровая механика

### Команда
- Выбор названия и цветов команды
- Найм пилотов
- Управление бюджетом

### Машина
Компоненты для улучшения:
- **Двигатель** - мощность и надежность
- **Шасси** - управляемость
- **Аэродинамика** - скорость на прямых
- **Шины** - сцепление с дорогой
- **Электроника** - стабильность

### Этапы чемпионата
- Проводятся автоматически каждые 2 дня
- Результаты зависят от характеристик машины и случайности
- Очки начисляются по системе Формулы 1

### Сезон
- Длительность: 1 месяц
- В конце сезона подводятся итоги и раздаются награды
- Начинается новый сезон с обнулением очков
