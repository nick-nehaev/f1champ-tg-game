# 3 в ряд - Игра для Telegram WebApp

Простая и увлекательная игра "3 в ряд" (Match-3) для Telegram WebApp.

## Описание

Классическая головоломка, где нужно составлять ряды из трёх и более одинаковых цветных гемов. Меняйте местами соседние гемы, чтобы создавать комбинации и набирать очки!

## Особенности

- Красочная графика с градиентами
- Плавные анимации и эффекты
- Система комбо для множественных совпадений
- Ограниченное количество ходов
- Полная интеграция с Telegram WebApp API
- Адаптивный дизайн для мобильных устройств
- Работает без сервера - только HTML/CSS/JS

## Правила игры

1. У вас есть 30 ходов для набора максимального количества очков
2. Нажмите на гем, затем на соседний, чтобы поменять их местами
3. Составьте ряд из 3 или более одинаковых гемов (по горизонтали или вертикали)
4. За каждое совпадение начисляются очки
5. Создавайте цепные реакции для получения комбо-бонусов!

## Система очков

- 3 гема = 10 очков
- 4 гема = 40 очков
- 5+ гемов = 50+ очков
- Комбо множители увеличивают счёт при цепных реакциях

## Запуск игры

### Локально

Просто откройте файл `index.html` в браузере.

### В Telegram

1. Разместите файл `index.html` на веб-сервере (GitHub Pages, Netlify, Vercel и т.д.)
2. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather)
3. Настройте WebApp URL в настройках бота
4. Добавьте кнопку с WebApp в меню бота
