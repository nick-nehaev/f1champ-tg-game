# 3 в ряд - Игра для Telegram WebApp

Простая и увлекательная игра "3 в ряд" (Match-3) для Telegram WebApp.

## Описание

Классическая головоломка, где нужно составлять ряды из трёх и более одинаковых цветных гемов. Меняйте местами соседние гемы, чтобы создавать комбинации и набирать очки!

## Особенности

- Красочная графика с градиентами
- Плавные анимации и эффекты
- Система комбо для множественных совпадений
- Ограниченное количество ходов
- Полная интеграция с Telegram WebApp API
- **Система донатов через Telegram Stars** ⭐
- Адаптивный дизайн для мобильных устройств
- Игра работает на GitHub Pages (без своего сервера)
- API для платежей на бесплатном Vercel

## Правила игры

1. У вас есть 30 ходов для набора максимального количества очков
2. Нажмите на гем, затем на соседний, чтобы поменять их местами
3. Составьте ряд из 3 или более одинаковых гемов (по горизонтали или вертикали)
4. За каждое совпадение начисляются очки
5. Создавайте цепные реакции для получения комбо-бонусов!

## Система очков

- 3 гема = 10 очков
- 4 гема = 40 очков
- 5+ гемов = 50+ очков
- Комбо множители увеличивают счёт при цепных реакциях

## Система донатов через Telegram Stars ⭐

Игроки могут поддержать разработку и получить бонусы:

| Сумма | Бонус |
|-------|-------|
| ⭐ 10 Stars | +5 ходов |
| ⭐ 50 Stars | +30 ходов |
| ⭐ 100 Stars | +75 ходов |
| ⭐ 250 Stars | +200 ходов |

**Преимущества Telegram Stars:**
- Встроенная платежная система Telegram
- Безопасные транзакции
- Не требуется подключение внешних платежных систем
- Моментальное начисление бонусов игрокам
- **Stars автоматически зачисляются на баланс владельца бота**
- Вывод Stars через @BotFather
- Подробнее: [STARS_BALANCE.md](STARS_BALANCE.md)

## Запуск игры

### Локально

Просто откройте файл `index.html` в браузере.

### В Telegram (с донатами)

#### Быстрый старт

1. **Деплой игры на GitHub Pages:**
   - Загрузите `index.html` в ваш репозиторий
   - Включите GitHub Pages в настройках репозитория
   - Игра будет доступна по адресу: `https://username.github.io/repo-name/`

2. **Деплой API на Vercel:**
   - Зарегистрируйтесь на [Vercel](https://vercel.com)
   - Импортируйте ваш GitHub репозиторий
   - Добавьте переменную окружения `BOT_TOKEN` (токен от [@BotFather](https://t.me/BotFather))
   - Деплой произойдёт автоматически

3. **Обновите API URL в игре:**
   - Откройте `index.html`
   - Найдите `const API_URL = 'https://your-vercel-app.vercel.app/api';`
   - Замените на ваш Vercel URL

4. **Настройте бота:**
   - Создайте бота через [@BotFather](https://t.me/BotFather)
   - Включите Telegram Stars в настройках бота
   - Настройте WebApp URL (ссылка на GitHub Pages)

📖 **Подробная инструкция:** см. [SETUP_PAYMENTS.md](SETUP_PAYMENTS.md)

## Как это работает

1. **Игра:** Размещается на GitHub Pages, работает полностью на клиенте
2. **Платежи:** При нажатии "Поддержать" игра отправляет запрос к Vercel Function
3. **API:** Vercel Function создаёт invoice через Telegram Bot API
4. **Оплата:** Telegram открывает форму оплаты Stars
5. **Бонусы:** После оплаты игрок получает дополнительные ходы
